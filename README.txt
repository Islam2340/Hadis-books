КАК ПОЛУЧИТЬ APK (один раз, бесплатно)

1. Зайди на github.com и зарегистрируйся (если нет аккаунта).
2. Нажми «+» вверху справа - New repository. Название любое, например hadisy. Лучше выбрать Public (публичный): в нём сборка бесплатная без ограничений по времени. Нажми Create repository.
3. На странице нового репозитория нажми «uploading an existing file» и перетащи ВСЁ СОДЕРЖИМОЕ распакованной папки: папки .github, app, tools и файлы build.gradle, settings.gradle. Нажми Commit changes.
   Если папку .github (она скрытая) перетащить не получается: Add file - Create new file, в названии напиши .github/workflows/build.yml и вставь туда текст из файла build.yml из этой папки.
4. Открой вкладку Actions. Сборка запустится сама. В ПЕРВЫЙ РАЗ она идёт долго (от 30 минут до 2-3 часов): GitHub скачивает языковую модель и считает «смысл» всех записей. Потом при повторных сборках быстро.
5. Когда появится зелёная галочка, открой сборку, внизу в разделе Artifacts скачай hadisy-apk (внутри app-debug.apk, около 150-200 МБ). Установи на телефон.

Если сборка закончилась красным крестиком: открой её, нажми на красный шаг, сделай скриншот текста ошибки и пришли мне.
